# 基地探索

以 Unity 6 與 C# 製作的單人動作探索遊戲原型。玩家從中央基地出發，擊敗各生態域的敵人取得素材，帶回資源建設基地、製作與強化武器，最終挑戰外圈守衛者。

> 目前為可遊玩的試玩版：包含三圈生態域、守衛解鎖、基地建設、武器／注魔、死亡遺失物、Boss 戰與試玩版結束。存檔、正式角色美術與音效刻意不在此版本範圍。

## 作品集目標

- 呈現 Unity 2D 遊戲迴圈、C# 遊戲規則、實體狀態、輸入與 HUD 架構能力。
- 以資料集中定義平衡數值，讓武器、敵人、區域與資源規則可獨立調整。
- 以 PC 與手機輸入支援為目標，建立可持續擴充的單人動作探索遊戲骨架。

## 開發重點

- **負責範圍：** 遊戲設計、Unity／C# 實作、系統架構、規則移植與可玩流程整合。
- **資料集中管理：** 武器、敵人、區域半徑與掉落素材定義在 `Definitions.cs`，避免平衡數值散落於每幀邏輯。
- **分層架構：** 實體狀態、背包、基地／裝備進程與 Unity 協調／表現分離；`GameBootstrap` 是唯一每幀進入點。
- **核心遊戲系統：** 自動鎖定戰鬥、近遠程攻擊、投射物、敵人追擊、守衛解鎖、資源掉落、基地建設、武器／模組與 Boss 戰。
- **雙平台輸入：** PC 支援鍵盤移動與衝刺；建置到手機時顯示虛擬方向、衝刺與互動按鈕。
- **工程取捨：** 畫面目前使用程式化 2D 示意物件，讓規則、輸入與流程先可獨立驗證；正式角色、敵人、地景與音效在後續里程碑整合。


## 操作

| 動作 | PC 鍵盤 | 手機 |
| --- | --- | --- |
| 移動 | WASD 或方向鍵 | 畫面左下方向按鈕 |
| 衝刺 | Shift | 右下「衝刺」 |
| 設施互動／建造 | F | 右側「互動」 |
| 切換已製作武器 | 1–4 | 基地設施選單 |
| 基地升級／製作 | 靠近基地後點選右側設施選單 | 靠近基地後點選右側設施選單 |

## 專案結構

```text
Assets/
  Scenes/
    Main.unity                 起始場景
  Scripts/
    Runtime/
      Definitions.cs           可調整的武器、敵人與世界資料
      Actor.cs                 玩家、敵人、投射物與掉落狀態
      Inventory.cs             背包堆疊與容量規則
      Progression.cs           基地倉庫與武器製作規則
      GameBootstrap.cs         遊戲迴圈、輸入、戰鬥、HUD 與 2D 表現
ProjectSettings/               Unity 專案與建置設定
Packages/                      Unity Package Manager 設定
```

## 遊戲內容

- 從基地往外探索森林、山脈與礦場；每擊敗一名守衛，便會全方向解鎖下一個區域。
- 透過自動鎖定的火把、彈弓、長槍與弓箭戰鬥，並使用升級與攻擊模組改變玩法。
- 在背包容量、生命與死亡後遺失資源間取捨；倉庫完成後，回到基地會自動存放資源。
- 擊敗第三圈守衛後進入荒地，挑戰具揮擊、衝刺與扇形彈幕的外圈守衛者。
